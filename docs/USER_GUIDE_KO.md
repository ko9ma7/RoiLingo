# RoiLingo 2.0 간단 사용 설명서


## 빠른 번역 기능

고정 ROI를 만들지 않고 화면 어디든 한 번만 번역할 수 있습니다.

- `Ctrl+Alt+T`: 화면을 잠시 캡처해 두고 마우스로 영역을 드래그 → OCR → 번역
- `Ctrl+Alt+W`: 현재 활성 창 전체 → OCR → 번역
- `Ctrl+Alt+V`: 클립보드 텍스트 → OCR 없이 번역

작은 메인 창의 **빠른번역** 버튼은 영역 번역이며, 버튼을 우클릭하면 활성 창/클립보드 번역 메뉴도 나옵니다. 결과 창은 일반 창처럼 이동/크기 조절할 수 있고 복사할 수 있습니다.

빠른 번역은 응답 속도를 위해 설정된 Provider 중 **첫 번째로 유효한 번역을 반환한 Provider** 결과를 사용합니다. 고정 ROI 실시간 모드는 기존 교차검증을 유지합니다.

## 평소에는 3단계만 사용

1. **대상**: 번역할 게임/프로그램 창을 클릭합니다.
2. **ROI**: 번역할 글자 영역을 지정합니다.
3. **시작**: 실시간 감시를 시작합니다.

기본값은 `원문 자동 감지 / OCR 영어+한국어 / 한국어 번역 / 무료 Web 3종 교차검증`입니다.

## 가려진 창 / 비활성 창

기본 캡처 방식은 **백그라운드 우선**입니다. 다른 창이 대상 창을 가려도 대상 HWND에 직접 `PrintWindow` 캡처를 먼저 요청합니다.

단, 최소화된 창이나 일부 GPU 전용 게임은 Windows/게임이 렌더링 자체를 중단해 검은 화면을 줄 수 있습니다. 이런 경우 RoiLingo는 가린 다른 창을 잘못 OCR하지 않고 캡처 실패로 처리합니다.

## 대상 창을 이동해도 ROI가 유지되는 이유

ROI는 바탕화면 절대 좌표가 아니라 대상 창 client 영역 안의 비율 좌표로 저장됩니다. 따라서 창이 왼쪽/오른쪽으로 이동해도 ROI는 같은 상대 위치를 사용합니다.

## 기존 ROI 수정

ROI 편집 화면에서:

- 빈 곳 드래그: 새 ROI 추가
- 기존 박스 드래그: 이동
- 선택 ROI 오른쪽 아래 파란 핸들 드래그: 가로/세로 크기 수정
- Delete/Backspace 또는 `선택 삭제`: 선택 ROI 삭제
- Enter 또는 `저장`: 완료

## 오버레이 크기

실시간 번역 중 **오버레이** 버튼을 누르면 편집 모드가 됩니다.

- 박스 드래그: 이동
- 파란 코너 핸들 가로 드래그: 너비
- 파란 코너 핸들 세로 드래그: 높이
- 휠: 너비
- Shift+휠: 높이
- Ctrl+휠: 투명도
- Alt+휠: 글자 크기

가로로 긴 박스, 세로로 긴 박스 모두 가능합니다.

## 빠른 시작

2.0부터 시작 버튼은 WebView/Papago/Google/DeepL과 모든 Tesseract 모델이 준비될 때까지 기다리지 않습니다. 감시를 먼저 시작한 뒤 필요한 구성만 첫 사용 또는 백그라운드에서 준비합니다.

관리자 이벤트처럼 빠르게 보고 싶은 ROI는 고급 설정의 ROI 목록에서 **이벤트**를 체크하면 일반 ROI보다 먼저 검사하고 빠른 OCR 경로를 사용합니다.

## UI 언어

작은 메인 창 오른쪽의 UI 언어 선택에서:

- 한국어
- English
- 日本語
- 简体中文

를 선택할 수 있습니다. 주요 메뉴와 탭, 언어명, 번역 모드 표시가 즉시 바뀝니다.

## 무료 번역과 API 번역

- 무료: Papago / Google / DeepL 웹 페이지 교차검증
- API/로컬: Papago API / Google API / DeepL API / LibreTranslate 호환
- 로컬 오픈소스: `scripts\libretranslate-local.cmd`

무료 웹 방식은 웹사이트 UI가 바뀌면 어댑터 보수가 필요할 수 있습니다. 장시간 무인 안정성이 중요하면 API/로컬 방식을 권장합니다.

## 순간 공지/이벤트 처리 (v2.1)

ROI에서 문장이 잠깐 나타났다 사라져도 RoiLingo는 변화 구간에서 가장 글자다운 프레임을 메모리에 보관한 뒤 OCR/번역을 끝까지 수행합니다. 번역 완료 결과는 번역 기록과 실행 로그에 남고, 게임 오버레이에는 기본 20초(이벤트 ROI는 최소 30초) 유지됩니다. `오버레이 설정`에서 ROI별 유지 시간을 0초로 지정하면 다음 번역이 나올 때까지 유지됩니다.

오버레이 편집 모드에서는 왼쪽 위 이동바로 위치를 옮기고, 오른쪽 파란 변은 가로만, 아래 파란 변은 세로만, 우하단 핸들은 가로/세로를 동시에 조절합니다. 드래그 중 전체 오버레이를 다시 만들지 않으므로 크기 조절이 끊기지 않습니다.
